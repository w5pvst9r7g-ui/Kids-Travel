☁️ Cloud sync

Back up every explorer's trips, badges & stories to your own free Supabase project, and restore them on any device. Your data stays in your account.

First-time setup (one minute)
  1. Make a free project at supabase.com.
  2. In the SQL editor, run the snippet below to create the table.
  3. Copy your Project URL and anon public key (Settings → API) into the boxes above.
  4. Pick a family code and use the same one on every device.
create table if not exists atlas_sync (
  code text primary key,
  payload jsonb,
  updated_at timestamptz default now()
);
alter table atlas_sync enable row level security;
create policy "atlas all" on atlas_sync
  for all using (true) with check (true);
